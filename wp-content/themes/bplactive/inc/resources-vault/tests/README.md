# To run unit tests for Resources Vault:

1. Install the WordPress PHPUnit test suite (see https://make.wordpress.org/core/handbook/testing/automated-testing/phpunit/)
2. From the theme root, run:

   vendor/bin/phpunit --bootstrap inc/resources-vault/tests/bootstrap.php inc/resources-vault/tests/
