# Contributing Guide

Thank you for considering contributing to this project!

## How to Contribute
- Fork the repository.
- Create a new branch for your feature or bugfix.
- Make your changes and commit them with clear messages.
- Push to your fork and submit a pull request.

## Code Style & Structure
- Follow WordPress coding standards for PHP files.
- Use consistent formatting for HTML, CSS, and JS files.
- Place all theme CSS in `assets/css/` and JS in `assets/js/`.
- Use template parts for modular PHP structure (header, footer, etc.).
- Use ACF for flexible content fields (e.g., campaign landing pages).

## Issues
- Please use the issue tracker to report bugs or request features.
